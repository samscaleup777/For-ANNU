Image transparency

Image sourcing & rights

Annïka uses product-specific image searches so each catalog item starts with an image query based on its own name, section, use case and relevant regional context.

Where imagery comes from

For catalog refinement, Annïka searches Openverse and Wikimedia Commons first, using product-specific terms and regional context spanning Bangladesh, Pakistan, the Arab world, the Gulf, South Asia and global Muslim communities where relevant.

Bangladeshi modest-fashion references

The modest-fashion banner uses product photography from Bangladeshi seller catalogues: Al Hurmat and Glam Touch's Haya Set Abaya. These are linked as source references, not represented as Annïka-owned products. Before selling these exact items or using the images in a commercial launch, obtain permission from the respective store or replace them with your own supplier-approved photos.

Product image rules

Catalog cards use each item's own product-specific image path first. The photo matcher now requires all meaningful product-name terms to match before substituting a licensed image. For hygiene, menstrual care, undergarments, skincare, makeup, medical/safety and other non-clothing products, person/model photos are rejected; when a suitable match is unavailable, the item's own catalog image remains instead of an unrelated picture.

What is not copied

Images from Facebook pages, boutiques, marketplaces or other commercial stores are not automatically free to reuse just because they are publicly visible. Those photographs should only be added when the owner has granted permission or the image is otherwise clearly licensed for the intended use.

Verification matters

Openverse aggregates media hosted by third parties and its documentation says developers should independently verify the license for each work. Wikimedia Commons likewise notes that each file can have different licensing and attribution conditions. Annïka therefore keeps source/credit information available for future catalog refreshes rather than treating a search result as blanket permission.

Catalog photographs are representative real-product/style references. They do not imply that Annïka owns the photographed brand or exact supplier SKU. Before commercial launch, replace any representative image with your own supplier/manufacturer photo where exact SKU identity matters.
